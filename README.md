# Scotykach

An Ableton Live plugin (VST3, AU, Standalone) that runs the firmware of the
[Synthux Spotykach](https://github.com/Synthux-Academy/spotykach), a
two-deck looping and granular instrument, on macOS.

Nothing is built yet. [docs/PLAN.md](docs/PLAN.md) has the build plan and
milestones, and what has been checked so far: the firmware's audio engine
(v1.3.1) builds and runs on a desktop without changes.
